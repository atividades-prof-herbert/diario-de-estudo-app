# UC-04 — Consultar histórico de estudos (por período)

**Produto:** Diário de Estudos  
**Objetivo:** permitir que o usuário consulte os registros de estudo em um período (dia/semana/mês), com dados suficientes para auditoria do que foi estudado.

## Atores

- **Usuário**
- **Sistema**

## Regras de negócio aplicadas

### RN-10 — Filtro por período
- O histórico deve aceitar filtros de período: **dia**, **semana**, **mês**.

### RN-11 — Ordenação
- Registros do histórico devem ser apresentados em ordem consistente (recomendado: **data decrescente**, depois **criado_em decrescente**).

### RN-12 — Identificação do vínculo
- Cada registro deve indicar claramente se foi lançado em **matéria** ou **tópico**.

### RN-04 — Taxa de acerto (referência)
- Se `questoes_feitas == 0`, taxa de acerto é **N/A**.

## Caso de uso: UC-04

### Pré-condições

- Pode existir 0 ou mais registros de estudo.

### Gatilho

- Usuário acessa a tela/ação **Histórico**.

### Fluxo principal (sucesso)

1. Sistema apresenta opções de filtro por período (dia/semana/mês) e seleção de referência (ex.: data base).
2. Usuário seleciona o período.
3. Sistema consulta os registros no intervalo correspondente.
4. Sistema exibe a lista de registros com, no mínimo:
   - data do estudo
   - referência (matéria ou tópico)
   - duração
   - questões feitas e corretas
   - (opcional) observações
5. Sistema aplica RN-11 (ordenação).

### Pós-condições

- Nenhuma alteração de estado.

## Fluxos alternativos / exceções

### A1 — Período sem registros
1. Sistema exibe estado vazio (“Sem registros no período”).
2. Sistema mantém opção de alterar o filtro.

### A2 — Período inválido
- Se o usuário informar um período inválido (ex.: data final < data inicial), o sistema deve recusar e solicitar correção.

## Cenários de validação

### CT-01 — Consultar histórico do dia com registros
**Dado** existem registros no dia selecionado  
**Quando** o usuário filtra por **dia**  
**Então** o sistema exibe apenas os registros daquele dia.

### CT-02 — Consultar histórico da semana
**Dado** existem registros na semana selecionada  
**Quando** o usuário filtra por **semana**  
**Então** o sistema exibe apenas os registros do intervalo da semana.

### CT-03 — Estado vazio
**Dado** não existem registros no período  
**Quando** o usuário consulta o histórico  
**Então** o sistema exibe “Sem registros no período”.

### CT-04 — Ordenação consistente
**Dado** existem múltiplos registros no período  
**Quando** o histórico é exibido  
**Então** os registros aparecem em ordem consistente (data desc, depois criado_em desc).

### CT-05 — Identificar vínculo
**Dado** existem registros vinculados a matéria e a tópico  
**Quando** o histórico é exibido  
**Então** cada item indica claramente seu vínculo (matéria ou tópico).
