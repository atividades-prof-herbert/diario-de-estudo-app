# UC-01 — Criar registro de estudo

**Produto:** Diário de Estudos  
**Objetivo:** salvar uma sessão de estudo associada a uma **matéria** ou a um **tópico**, registrando duração e desempenho em questões.

## Atores

- **Usuário**
- **Sistema**

## Regras de negócio aplicadas

### RN-01 — Vínculo do registro (exclusivo)
- Um registro deve se vincular a **exatamente um** destes:
  - Matéria; ou
  - Tópico.

### RN-02 — Consistência de questões
- `questoes_feitas >= 0`
- `questoes_corretas >= 0`
- `questoes_corretas <= questoes_feitas`

### RN-03 — Duração
- `duracao_minutos > 0`

### RN-04 — Taxa de acerto
- Se `questoes_feitas == 0`, taxa de acerto é **N/A** (não calcular percentual).

## Caso de uso: UC-01

### Pré-condições

- Existe pelo menos uma matéria cadastrada.
- Se o usuário for registrar por tópico, existe pelo menos um tópico cadastrado para alguma matéria.

### Gatilho

- Usuário aciona a ação **“Novo registro de estudo”**.

### Fluxo principal (sucesso)

1. Sistema solicita o tipo de vínculo: **Matéria** ou **Tópico**.
2. Usuário seleciona o vínculo e a referência (`referencia_id`).
3. Sistema apresenta os campos do registro: `data`, `duracao`, `questoes_feitas`, `questoes_corretas`, `observacoes`.
4. Usuário informa os valores e confirma **Salvar**.
5. Sistema valida regras RN-01, RN-02 e RN-03.
6. Sistema persiste o registro.
7. Sistema retorna sucesso e o `id` do registro.
8. Sistema garante que o novo registro fique acessível:
   - na consulta de histórico do período; e
   - no recálculo/consulta de resumos (se aplicável).

### Pós-condições

- Registro criado e consultável.
- Dados agregados (quando consultados) refletem o novo registro.

## Cenários de validação

### CT-01 — Registrar estudo por matéria (com questões)
**Dado** uma matéria existente `M1`  
**Quando** o usuário cria um registro com `referencia_tipo=MATERIA`, `referencia_id=M1`, `duracao_minutos=60`, `questoes_feitas=20`, `questoes_corretas=15`  
**Então** o registro é salvo  
**E** o histórico do período inclui o registro  
**E** o resumo de `M1` soma +60min, +20 feitas, +15 corretas e taxa 75%.

### CT-02 — Registrar estudo por tópico (sem questões)
**Dado** um tópico existente `T1`  
**Quando** o usuário cria um registro com `referencia_tipo=TOPICO`, `referencia_id=T1`, `duracao_minutos=30`, `questoes_feitas=0`, `questoes_corretas=0`  
**Então** o registro é salvo  
**E** o resumo do tópico soma +30min  
**E** a taxa de acerto é exibida como **N/A**.

### CT-03 — Bloquear quando `questoes_corretas > questoes_feitas`
**Dado** uma referência válida (matéria ou tópico)  
**Quando** o usuário tenta salvar `questoes_feitas=10` e `questoes_corretas=12`  
**Então** o sistema deve rejeitar o salvamento  
**E** informar o motivo (corretas não pode ser maior que feitas).

### CT-04 — Bloquear quando `duracao_minutos <= 0`
**Dado** uma referência válida (matéria ou tópico)  
**Quando** o usuário tenta salvar `duracao_minutos=0` (ou negativo)  
**Então** o sistema deve rejeitar o salvamento  
**E** informar o motivo (duração deve ser maior que zero).

### CT-05 — Bloquear quando não há referência selecionada
**Quando** o usuário tenta salvar um registro sem `referencia_tipo` e/ou sem `referencia_id`  
**Então** o sistema deve rejeitar o salvamento  
**E** solicitar a seleção de matéria ou tópico.
