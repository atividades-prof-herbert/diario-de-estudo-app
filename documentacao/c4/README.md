# Diagramas C4 — Diário de Estudos

Este diretório contém os diagramas no padrão **C4 Model**, descritos em **PlantUML**.

O C4 Model descreve a arquitetura de software em níveis de zoom, do mais alto nível (contexto) até o detalhamento interno (componentes).  


## Arquivos

- `c4-01-contexto.md` — **System Context**: mostra o sistema como uma “caixa”, quem usa e quais sistemas externos ele integra.
- `c4-02-container.md` — **Container**: mostra os principais blocos executáveis (apps, APIs, bancos, filas) e como se comunicam.
- `c4-03-component.md` — **Component**: detalha, dentro de um container, os principais componentes e suas responsabilidades/interações.
